Install my own server (test)

This page puts a copy of the TF-Tracker server script into your own Google account, so your users' work runs on your account and not on the shared server. It needs your permission once.

Before you start (one time)

  1. Open script.google.com/home/usersettings and turn Google Apps Script API = ON.
  2. Use the Google account that should own the server (the same one that owns your Google Sheet).

Install

Almost done - authorize once

  1. Open the script editor.
  2. At the top choose the function authorizeAll and press Run.
  3. Press Review permissions, choose your account, Advanced → Go to ... (unsafe) → Allow. (This warning is normal for your own script.)
  4. Then press Deploy → Manage deployments only if you changed the code. Not needed now.
